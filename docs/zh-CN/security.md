## 工作区文件工具

`os.Root` 可降低逃逸工作区根目录的风险。程序拒绝绝对路径、`..` 路径组件和符号链接组件。常见密钥位置（`.env*`、`.ssh`、`.aws`、凭据文件名和私钥扩展名）、生成目录及匹配 `.gitignore` 的路径会从常规读取/搜索/列表工具中排除。读取仅接受不超过 128 KiB 的常规 UTF-8 文本文件。这是排除规则，并非通用密钥检测器。嵌套 ignore 采用保守策略：父目录排除后，子目录的例外不能重新开放路径。

提案本身不会写入文件。替换/删除操作会显示统一 diff；移动操作会显示源、目标和受影响内容。批准仅适用于单项操作。修改前会重新校验原文件 digest。替换使用独占临时文件、fsync 和 rename；移动会先独占创建目标，再删除源文件。如果无法删除源文件，程序会报告部分结果而不会谎称成功。可在根目录内创建父目录；移动不会覆盖无关的目标文件。

这些边界用于防止模型提供恶意路径，不能防御并发的恶意本地进程、硬链接或由同一操作系统用户控制的挂载文件系统。digest 校验不是整个文件系统上的 compare-and-swap；应用修改期间应避免外部并发编辑。runtime 按工作区互斥，避免两个智能体任务同时修改同一工作区。

## Linux 进程隔离

默认 shell 执行使用 Bubblewrap。如果 Bubblewrap 不可用或被主机策略阻止，程序会拒绝执行。沙箱将 `/usr` 和必要的系统 runtime 目录设为只读，提供临时 `/tmp`、受限设备，并将所选项目挂载到 `/workspace`。主机 home 和 `/proc` 不可见。项目中的受保护密钥会被屏蔽；依赖目录仍可用，以便构建项目。程序请求独立命名空间、新会话和父进程退出后的终止。这并不代表可以防御内核漏洞或侧信道。

默认隔离网络。显式授予网络权限后，执行会共享主机网络并挂载必要的解析器/证书文件；审批界面会标记该命令启用了网络。显式授予安装权限后，才可使用软件包安装工具。通用 shell 代码仍可能在获准的文件/网络边界内执行等效操作，因此工具类别本身并不能为任意程序提供语义隔离。

macOS 和 Windows 当前没有内置进程沙箱。要求强制隔离的命令会被拒绝。`--allow-unsandboxed-shell` 会在所有平台上显式启用以主机用户权限执行命令，并在每项命令前要求批准和展示警告。它可以访问主机路径、网络和已安装应用。需要强 OS 边界时不要启用此模式。程序不会自动提升权限。

子进程只接收小范围的环境变量白名单，不会收到服务提供商凭据。不过，主机模式仍可能读取主机文件中的凭据。命令最长运行 60 秒，stdout/stderr 均有限制。Unix 上取消 shell 会终止进程组；自动化 worker 也使用进程组。Windows 使用 taskkill 终止进程树。主动分离的进程和已完成的操作不一定可以逆转或终止。这些是取消机制，不是 macOS/Windows 的 OS 隔离。

## Runtime

随机生成的 256 位 token 用于认证 loopback IPC。token 文件是私有的，不会显示；客户端会拒绝非 loopback 地址和重定向。请求大小有限，方法/路由经过验证，浏览器 cross-origin 请求会被拒绝。OS 锁用于防止重复 daemon，并会在崩溃后自动释放。只有取得锁后才会替换元数据。协议不兼容时会报错，而不会静默复用不兼容状态。

审批 ID 是随机、一次性并绑定到发起请求的客户端身份。只有 runtime 可以更改存储；客户端直接追加消息/摘要/用量会被拒绝。活动会话不能删除、恢复、重命名或导出。任务按会话和工作区串行执行。客户端断开只取消自己的请求，其他客户端继续工作。若仍有活动任务，runtime 不允许停止；操作系统终止时会先取消任务再关闭存储。

经过认证的本地用户可以配置授权和 endpoint。认证并不意味着 AI 生成的命令可信：所有修改、shell 命令和自动化操作仍需批准，`inspect` 模式会拒绝这些操作。

## 密钥、审计与上下文

凭据来自环境变量、操作系统密钥链或显式选择的文件回退方式。Unix 上权限对组/其他用户开放的凭据文件会被拒绝。新文件使用 0600 权限，目录使用 0700；Windows 依赖用户配置文件 ACL。密钥不会写入 JSON 配置。已知凭据值和终端控制字符在显示/保存前会被脱敏。无法可靠检测任意应用密钥；不要要求工具打印这些内容。会话在磁盘上不加密。

SQLite 会在执行前记录提案和审批。持久化失败会停止操作。任务开始/结束及配置变更会写入审计记录。如果文件修改已发生但结果未能持久化，恢复时会提示结果未知，不会自动重放。runtime 日志记录操作元数据，不记录请求正文或截图数据。

原始历史是权威来源。结构化摘要保留来源 ID，但不赋予权限。`recall` 会分块检索原始历史。截图只在内存中暂存：持久化内容仅保留占位标记，图像会在当前任务期间发送给配置的模型。用户必须授权截图，选择支持图像的模型，并注意屏幕上可见的信息。

## 浏览器与原生桌面

浏览器和原生桌面是独立工具，需要单独启用和审批。剪贴板另需授权。Playwright worker 使用全新配置文件和精确 origin 页面路由策略，阻止下载、service worker 和 WebSocket，并限制步骤/时间/输出，报告真实失败。页面路由策略不是操作系统级网络隔离。

原生输入作用于用户当前可见的桌面。启动/聚焦应用会使用白名单；全局鼠标/键盘手势不会被限制在单一进程。用户必须在批准前查看目标和操作。程序遵守辅助功能/屏幕录制权限、锁定/UAC 安全桌面和 compositor 限制。内置 Linux X11 后端不支持 Wayland。外部适配器属于受信任的用户配置，必须自行实施操作系统策略。参阅[自动化协议](automation.md)。
