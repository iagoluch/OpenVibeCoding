Link de abertura

Este link não vale mais

Cada link de abertura serve para uma única entrada e expira em 5 minutos. Isso é o que mantém o painel restrito a quem está no seu computador.

Para abrir o painel, rode no terminal:

ovc --ui

O comando imprime um link novo e abre o navegador. Vale para o navegador que abriu o link; se você usa outro, rode o comando de novo e abra o link nele.
