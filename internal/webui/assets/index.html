    Painel local

    Conecte esta aba ao OpenVibeCoding

    Este painel roda dentro do seu computador, ao lado do que você já usa no terminal. Para abrir aqui, o terminal libera esta aba uma única vez.

    1. No terminal, rode o comando:

      ovc --ui

    2. O navegador abre um link de uso único, válido por 5 minutos.

    3. Assim que o link abrir, esta página entra sozinha.

    O que costuma resolver

    • O link expirou ou já foi usado. Cada link vale para uma abertura. Rode ovc --ui outra vez para gerar um novo.
    • O link foi aberto em outro navegador. A autorização vale para o navegador que abriu o link. Rode ovc --ui e abra o novo link aqui.
    • O serviço parou. Se você fechou o terminal onde o ovc rodava, rode ovc --ui de novo: ele sobe o serviço e imprime um link novo.
    • Você está no endereço errado. O painel responde apenas no endereço 127.0.0.1 desta máquina.

          Como este painel funciona

          Atalhos

          • Enter envia a mensagem · Shift+Enter quebra a linha.
          • Esc interrompe o que estiver rodando; com uma aprovação na tela, ela é recusada.
          • Ctrl+K abre os comandos · ? abre esta ajuda.
          • Ctrl+F vai para a busca da conversa.

          O que o agente pode fazer sozinho

          Ler arquivos, listar o projeto, procurar texto e inspecionar o Git acontecem sem interromper você. Tudo que muda o projeto — escrever, apagar, mover, rodar comando, usar navegador ou desktop — para numa aprovação e espera a sua resposta.

          Aprovações

          Cada pedido mostra o que será feito e o texto exato que o agente enviou. Permitir executa aquela operação uma vez; Recusar devolve a recusa ao agente, que segue por outro caminho. Aprovar aqui vale só para esta operação.

          Limites

          • O agente trabalha dentro da pasta da sessão e não alcança caminhos protegidos como .git, chaves e .env.
          • Comandos rodam em modo confinado quando o sistema oferece isolamento; sem isolamento, o comando é recusado em vez de rodar sem proteção.
          • A conversa, os usos e a auditoria ficam no computador que roda o ovc. Só o texto enviado ao modelo sai daqui.
